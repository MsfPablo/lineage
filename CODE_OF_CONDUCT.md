# Code Of Conduct

We want Lineage to be a practical, respectful project for people building safer agent tooling together.

Be kind, direct, and constructive. Assume good intent, but respect boundaries. Do not post secrets, private workflow content, or sensitive user data in issues, pull requests, examples, or discussions.

Unacceptable behavior includes harassment, threats, discriminatory language, and deliberate disruption of project spaces.

Maintainers may remove content or restrict participation when needed to keep the project healthy.
